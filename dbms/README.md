setiap system branch. Setiap file adalah baseline domain yang dapat diimpor ke dbdiagram.io dan
diturunkan menjadi migration Laravel.

## Konvensi

- Semua tabel transaksi memiliki `created_at` dan `updated_at`.
- Foreign key memakai `ref` eksplisit agar migrasi dapat dibuat deterministik.
- `users` adalah boundary actor minimal; implementasi Laravel dapat menggantinya dengan tabel
  shared dari aplikasi utama.
- Status dan aturan bisnis rinci perlu dikunci sebelum migration production dibuat.

Dokumentasi implementasi branch POS tersedia di
[`docs/point-of-sales-system.md`](../point-of-sales-system.md).
